# v0.4.3b

发布日期：2026-10-05

变更时间：2026-10-05

本次更新重做 AI 平台配置流程：默认不再预置任何已配置的模型提供商，改由前端内置模板驱动「添加平台」，并在后端补齐「列出 / 删除平台」接口、权限与操作日志；同时修复一批交互与导入问题（控制台回车卡死、封面被裁剪、ESC 关闭剧本编辑器、开关颜色、baseurl 被自动补全等），拆分超长模块并清理无用代码。发布包同时调整打包原则：开启首次部署引导，且不打包自动构建与开发侧功能。

## AI 平台配置（重做）

- **默认不预置平台**：新部署的 `data/config/aiplatform/` 只保留 `default-request.json`，不再随包提供 `aliyun / deepseek / lmstudio / openai / openrouter / siliconflow` 等已配置好的平台，用户进入后在「添加平台」里自行创建第一条。内置能力仅以「模板」形式保留在前端，用于预填。
- **「添加平台」弹窗**：
  - 顶部居中为供应商头像选择区：未选择时按供应商名称首字生成文字头像（色相由名称推导，稳定区分），选择内置供应商时使用内置头像；用户仍可自行上传覆盖（data URL，上限 1MB）。
  - 依次为供应商名称（选择内置自动填写、可修改）、API Key、baseurl；baseurl 右侧新增「完整 URL」开关：关闭时程序自动拼接 `/chat/completions` 等后半段，用户只需填写兼容服务的端点地址（不以斜杠结尾即可），打开时按用户填写的完整地址请求。
  - 折叠的「高级选项」包含：提供商类型（OpenAI 官方格式 / OpenAI 兼容 / Anthropic，选择内置自动填写）与请求模型（可添加多个，每个可勾选为默认启用）。
  - 右下角为「取消 / 测试连接 / 添加（编辑时为保存）」；「测试连接」沿用既有的平台测试方法。
- **供应商卡片**：保存后渲染为横向一条卡片——左侧头像、供应商名称，右侧置右排列「启用」（点击后变色且文字变为「使用中」，同时启用平台）、「编辑」「检测连通」（均为纯图标，检测连通复用既有测试方法）、「删除」控件。
- **后端接口与治理**：新增 `GET /api/config/aiplatform`（列出磁盘上的全部平台，读取时剥离 api_key）与 `DELETE /api/config/aiplatform/<platform>`（删除平台配置、对应 secret 及该平台的模型请求模板目录）；两者均要求 `settings.ai_models` 权限节点并写入操作日志。
- **配置元数据**：平台配置新增 `provider_type`、`base_url_full`、`default_model` 字段（仅作元数据持久化 / 展示，不改变后端聊天请求构造）。
- **内置模板**：阿里云百炼、硅基流动、DeepSeek、OpenRouter、LM Studio、OpenAI；LM Studio 现可选择具体模型，并作为 OpenAI 兼容平台使用。

## 模型请求与 Responses API

- `base_url` 不再由用户在输入后被动补全：新增 `ai_capabilities.chat_completions_endpoint()` 统一在请求时归一化端点，用户填写的地址不会再被就地改写成 `/v1/chat/completions`。
- 新增 Responses API 能力探测与传输层（`ai_capabilities.probe_responses_api` / `agents/responses_transport.py`）：对支持 `/responses` + `previous_response_id` 的端点做轻量真实探测，仅在用户显式开启且探测通过时启用有状态续答以减少重复计费；任何异常立即锁定并回退到 chat/completions。
- 每个模型平台新增「请求模板」按钮，用户可自行编辑该模型请求体的写法（沿用 `data/config/aimodel/<platform>/<model>.json`）。

## 剧本编辑与导入

- 剧本编辑界面的封面图片不再被错误裁剪；「上传封面」按钮文字右侧的多余空白去除。
- 剧本编辑器支持按 `Esc` 或点击窗口遮罩关闭；剧本内有改动时，关闭前按与关闭按钮一致的文案询问是否保留草稿。
- 剧本导入支持 `.doc`（与既有 `.docx` / `.doc` 等一并通过文本抽取管线处理）。
- 模块摘要与剧本导入共用的 AI 接入逻辑从 `routes/scenarios.py` 抽出为 `scenario_ai.py` / `routes/scenario_summary.py`，路由层只负责 HTTP 编排。

## 界面与交互修复

- 控制台按回车不再导致控制台失去响应。
- 开关控件颜色修正：选中态统一使用主题色（不再固定为蓝色），聚焦 / 失焦时原点不再在灰与蓝之间闪烁。
- 保存模型平台配置成功后的提示由浏览器原生弹窗改为网页内提示。
- 角色卡标签卡右上角「角色卡广场」按钮现可正确跳转到「探索发现」中的角色卡广场。
- AI 在聊天中返回的错误信息进行 i18n。
- 新增 debug 模式：仅当管理员开启后，日志才打印完整的 AI 请求与返回内容。

## 首次部署引导与发布

- 首次部署引导开启：发布包内 `data/config/site.json` 的 `setup_dismissed` 置为 `false`，且不包含任何 OWNER 数据，使 `/api/setup/status` 返回 `setup_required=true`，启动后即进入引导。
- 发布包不预置模型提供商：不打包 `data/config/aiplatform/*.json`（仅保留 `default-request.json`）与 `data/config/aimodel/**`。
- 发布包不包含自动构建：`server.py` 的前端自动构建改为开发侧开关 `AI_TRPG_DEV_BUILD=1`（默认关闭），发布包直接使用随包的 `dist/` 构建产物，且在没有 npm 的环境也能正常启动。
- 发布包排除开发侧内容：`tests/`、开发 / 校验脚本与内部计划文档等不再打包。
