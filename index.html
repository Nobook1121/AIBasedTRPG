Built for the whole table

一套 AI KP 引擎，撑起整张跑团桌。

它不是一个只会续写剧情的聊天框。叙事、检定、世界书与角色状态各自分工，跑团过程才推得下去。

01

AI KP，不抢走规则

自然语言叙事与结构化状态分开处理。模型负责讲故事，引擎让检定结果、技能值与角色卡真正落地。

02

一张实时多人桌

房间码邀请、成员列表、角色变更实时同步、正在输入提示。页面与实时聊天走同一个端口，WebSocket 不可用时自动回退长轮询。

03

世界书会记得

命中触发词直接激活，未命中回退 BM25 + 向量检索；支持常驻条目、分层、概率、粘滞与冷却轮数，AI 只读到它此刻该读的部分。

04

剧本从文档开始

把 Word / PDF / Markdown 模组丢进来，按标题分节、切块、建索引，导入完成即可游玩；也可以先让 AI 转成结构化剧本，你检查修改后再发布。

05

规则不被写死

COC7 技能基础值支持「房规 > 管理员默认 > 规则书默认」三级覆盖；检定名对照 character_skills.json（含专精与中文变体）校验，未知名直接拒绝并提示。

06

部署在你手里

单进程运行，不需要 Docker 也能跑。预置 DeepSeek / OpenAI / 阿里云百炼 / SiliconFlow / OpenRouter / LM Studio 六家平台，也支持任意 OpenAI 兼容接口。

Story, with consequences

叙事可以自由，状态必须可信。

玩家看到的是干净的叙事，背后每一次检定、技能变动与存档都由引擎处理。

  • 检定先掷骰，结果再被叙述。KP 不会先写好结局再补一个骰点。
  • 技能上限改动后按最终值裁剪所有技能点数，不会留下越界的分配。
  • 剧情不会丢。聊天记录持久保存，可打回档节点，也可按周期自动存档。
  • 中途换剧本也不乱。换成同一剧本的最新版本可继承剧情进度，换别的剧本则重置。

Import modes

「直接导入」的剧本按只读处理：不提供场景栏位编辑，只保留基础信息与触发器资源，避免误改把检索索引弄坏。

只改标题、作者、封面、简介这类基础信息不会升版本，也不会重算索引；只有改动剧本内容才会生成新版本。

Python · Three commands

跑起来只需要一个终端。

需要 Python 3.11+；Node.js 18+ 只在你自己构建前端时才会用到。

PowerShell 
git clone https://github.com/Nobook1121/AIBasedTRPG
cd "AIbased TRPG"

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

npm install
npm run build:frontend

python server.py

Deploy anywhere

域名和 HTTPS，交给反向代理。

程序本身不内置穿透、端口映射与 HTTPS，长期运行交给 Nginx 或 Caddy，记得转发 WebSocket。

  • 同一台电脑：直接 python server.py，浏览器开 127.0.0.1:8086。
  • 局域网：主机启动服务，朋友访问主机 IP，记得放行防火墙端口。
  • 异地联机：ZeroTier / Tailscale / WireGuard / frp 组网或穿透，也可以直接上云服务器。
  • 上线前务必设置自己的密钥：$env:AI_TRPG_SECRET_KEY，不要用默认开发密钥。
Nginx
location / {
    proxy_pass http://127.0.0.1:8086;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
}
Questions

上手前可能想知道。

打开页面是空白的？

前端没有构建。执行 npm install && npm run build:frontend，或者改用已经带构建产物的 release 压缩包。

朋友连不上？

依次检查三件事：主机防火墙有没有放行端口、IP 对不对（异地组网要用虚拟网卡 IP）、启动日志里有没有对方能访问到的 listening 地址。

AI 不回复，或者只回复一半？

多数是模型接口超时。可以在设置页调大「AI 请求超时」和「最大工具调用轮数」，再确认 API Key 与模型 ID 没写错。

扫描版 PDF 导进来没有内容？

默认只处理文本型 PDF。扫描件需要额外装 OCR 依赖（PaddleOCR），见开发文档里的进阶可选项。

改了剧本标题或封面，版本号为什么没变？

这是刻意的。标题、作者、推荐人数、简介、封面都属于基础信息，改它们不会升版本、也不会重算索引；只有改动剧本内容才会生成新版本。
