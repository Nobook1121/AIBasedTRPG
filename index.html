特色功能

一个能自己跑的 AI 跑团平台

从剧本导入、世界书检索，到角色卡、检定与多人房间，全部装在一个单进程服务里。

AI 守秘人全程主持

记住当前场景、已发生的剧情与玩家行为，按需检索剧本内容，不会一次性把剧透全倒出来。

COC7 角色卡与检定

属性、技能、武器、专精一应俱全；技能基础值支持「房规 > 管理员默认 > 规则书默认」三级覆盖。

两种剧本导入方式

直接导入：文档自动分节、切块、建索引，导入即可玩；审核导入：AI 先转成结构化剧本，你改完再发布。

世界书可视化编辑

按章节查看 AI 实际会读到的内容，手动调整触发词、常驻、分层、概率、粘滞与冷却轮数。

触发器资源库

给剧本挂图片、音频、视频、富文本或附件，按场景进入、线索发现、NPC 对话等条件自动推送，并可设置剧透等级。

多人房间与存档

房间码邀请、成员与角色实时同步；聊天记录持久保存，支持手动回档节点与周期自动存档。

细粒度权限

OWNER / ADMIN / USER 三级身份之外，还能按功能节点逐项勾选权限，权限页面已完整中文化。

AI 用量看板

按天统计 token 消耗、缓存命中率，以及各剧本与房间的成本分布，心里有数。

中英双语与多主题

内置 i18n 可实时切换并记住选择；明亮、暗色、赛博档案、秘典·羊皮纸四套主题随你挑。

怎么玩

四步开一局

部署并打开首页

首次访问自动弹出 5 步向导：配置 AI → 起站名 → 绑定域名（可跳过）→ 创建 Owner → 进入系统。

准备剧本

手动创建模组，或把 Word / PDF / Markdown 剧本文档直接丢进来，自动切块建索引。

开房间、发房间码

填房间名、选剧本，创建后拿到房间码；朋友用房间码加入，聊天记录切换为该房间的持久记录。

开跑

AI 自动开场并推进剧情。玩家掷骰、检定、行动；KP 需要时推送线索与触发器内容，随时可打回档节点。

快速开始

三条命令跑起来

需要 Python 3.11+；Node.js 18+ 只在自行构建前端时需要。

PowerShell 
git clone https://github.com/Nobook1121/AIBasedTRPG
cd "AIbased TRPG"

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

npm install
npm run build:frontend

python server.py
场景 做法
同一台电脑 直接 python server.py，浏览器打开 http://127.0.0.1:8086。
局域网 主机启动服务，朋友访问 http://<主机IP>:8086，记得放行防火墙端口。
异地联机 用 ZeroTier / Tailscale / WireGuard / frp 组网或穿透，也可直接部署到云服务器。

如果使用的是 release 压缩包，里面已经包含构建好的前端：解压后只需 pip install -r requirements.txt 再 python server.py 即可。

部署

程序本身不内置穿透与 HTTPS

域名与 HTTPS 交给 Nginx / Caddy 等反向代理，记得转发 WebSocket。

Nginx 反向代理示例
location / {
    proxy_pass http://127.0.0.1:8086;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
}

长期运行务必设置自己的密钥：$env:AI_TRPG_SECRET_KEY = "换成你自己的随机字符串"。并建议给每位朋友单独开账号、只对外开放程序端口、定期备份 data/。

常见问题

上手前可能想知道

打开页面是空白的？

前端没有构建。执行 npm install && npm run build:frontend，或改用包含构建产物的 release 压缩包。

朋友连不上？

依次检查：主机防火墙是否放行端口、是否用了正确的 IP（异地组网要用虚拟网卡 IP）、启动日志里是否有对方能访问到的 listening 地址。

AI 不回复或只回复一半？

多为模型接口超时。可在设置页调大「AI 请求超时」与「最大工具调用轮数」，并确认 API Key 与模型 ID 正确。

扫描版 PDF 导入后没有内容？

默认只处理文本型 PDF，扫描件需要额外安装 OCR 依赖（PaddleOCR，见开发者文档的进阶可选项）。

改了剧本标题/封面，为什么版本号没变？

这是刻意的：标题、作者、推荐人数、简介、封面属于基础信息，修改它们不会升版本、也不会重算索引；只有改动剧本内容才会生成新版本。
